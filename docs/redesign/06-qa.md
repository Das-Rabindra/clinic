## 2. Functional regression (vs `00-baseline.md`)

- **Routes:** all 17 sitemap URLs return 200. `/nope` returns 404 with the
  site layout. `/css/site.css` returns 404 (retired). `/admin/login` returns
  200, and the admin assets load.
- **Links and assets:** 74 unique references checked; **0 broken**. Three
  apparent 404s were the checker splitting map URLs at the comma inside the
  coordinates.
- **Contact actions:** tel, WhatsApp, directions and review links are
  unchanged from baseline.
- **Navigation:** hash links work from every page (`/#about` etc.). The
  drawer opens with focus moved in, Tab trapped, and Esc closing it.
- **Booking:**
  - deep link works
  - calendar, slots and validation work
  - confirmation (mocked on production; real on the local database)
  - find and cancel (local database)
  - all 15 Stage 5 browser tests pass
- **Call-back:** validation, focus trap, and submit to Admin → Enquiries
  (local database). The failure path keeps typed values.
- **Action bar:** exactly one below 1024 px on every page and width, with
  space reserved under it.

## 3. Accessibility

- Lighthouse accessibility is **100 on all 17 pages** (baseline: 94–95).
- One h1 per page and no skipped heading levels (all 15 treatment pages
  tested).
- **Focus visible and not obscured (WCAG 2.4.7 / 2.4.11):** every focus stop
  was tabbed through on `/` (83–88 stops), `/services`, a treatment page and
  `/privacy`, at 390 and 1440 px.
  - **Found:** on phones, a footer link focused at the bottom of the screen
    sat behind the fixed action bar.
  - **Fixed** with `scroll-padding-bottom` while the bar is shown. After the
    fix: 0 problems on all five page/width runs.
  - The booking radio inputs show their ring on the surrounding card
    (`:has(:focus-visible)`), which is correct; the checker can't see it.
- **Contrast:** every token pair is asserted by `test/design-tokens.test.mjs`
  (39 checks).
- **Reduced motion:** asserted in tests.
- **Dialogs:** native `<dialog>`, with focus in, Tab wrapped and focus
  returned. The accordion works without JS. The carousel has no autoplay.
- **Forms:** `aria-invalid`, `aria-describedby`, live summary, focus on the
  first error.

## 4. Responsive
